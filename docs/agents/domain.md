# Domain Documentation Layout

The project uses a single-context layout:

- **Canonical Glossary:** `GLOSSARY.md` at repo root.
- **Master Business Requirements:** `BRD.md` at repo root.
- **Engineering Philosophy & Guardrails:** `AGENTS.md` at repo root.
- **Architecture Decision Records (ADRs):** `specs/changes/XXXX-name.md`.

All skills reading or writing domain specifications must adhere to the definitions in `GLOSSARY.md` and the SEBI non-advisory constraints in `AGENTS.md`.
